ПРО КУРС

Граматична основа для послідовної роботи з мовою

Grammar Foundation зосереджений на основних граматичних темах: структурі речення, формах дієслів, запитаннях, запереченнях та базових часових моделях.

Матеріал поділений на окремі граматичні блоки, щоб правило, приклади та вправи можна було опрацьовувати у зрозумілій послідовності.

01

Grammar

Основні правила, форми дієслів та граматичні моделі.

02

Structure

Порядок слів, побудова речень та зв’язок між частинами.

03

Practice

Вправи та приклади, які допомагають закріплювати граматичні теми після пояснення.

ЗМІСТ ПРОГРАМИ

Шість модулів для роботи з базовою граматикою

Кожен модуль присвячений окремій граматичній темі та практиці її використання.

MODULE 01

Sentence Basics

Порядок слів, підмет, присудок та базова структура англійського речення.

MODULE 02

Present Simple

Ствердження, заперечення, запитання та типові моделі Present Simple.

MODULE 03

Past Simple

Основні форми минулого часу, регулярні та поширені неправильні дієслова.

MODULE 04

Questions & Negatives

Побудова запитань, заперечень та коротких відповідей.

MODULE 05

Articles & Nouns

Артиклі, іменники, однина, множина та базові правила вживання.

MODULE 06

Grammar Review

Повторення ключових правил, змішані приклади та підсумкові вправи.

КОМУ ПІДІЙДЕ

Для систематизації базової англійської граматики

Рівню A1–A2

Для тих, хто вже знає базові слова та хоче послідовно розібрати основні граматичні правила.

Для повторення правил

Для тих, хто вже вивчав граматику, але хоче повернутися до основних тем у впорядкованому форматі.

Для систематизації

Для тих, кому потрібно поєднати окремі правила у більш цілісну граматичну систему.

Перед рівнем B1

Для повторення граматичної бази перед переходом до складніших програм рівня B1.
